# Aplikasi To-Do List

## Deskripsi
Aplikasi sederhana berbasis PHP untuk mencatat tugas harian. Daftar tugas disimpan di session sebagai array PHP, dan tampilannya memakai Bootstrap 5 dari folder `assets`.

## Fitur
- Tambah tugas lewat modal
- Edit nama tugas lewat modal
- Tandai tugas selesai dengan checkbox
- Hapus tugas

## Struktur Folder
- `index.php` - halaman utama
- `assets/bootstrap-5.3.8/` - file CSS dan JS Bootstrap

## Cara Menjalankan
1. Salin folder ke `www/`
2. Jalankan WAMP dan buka di `http://localhost/todolist`
